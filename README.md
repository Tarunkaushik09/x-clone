# X (Twitter) Web UI Clone

A responsive, pixel-perfect frontend clone of the **X (formerly Twitter)** web interface built from scratch using modern semantic HTML and Tailwind CSS.

---

## 🚀 Live Demo

[View Live Project](https://<Tarunkaushik09>.github.io/x-clone/)

---

## ✨ Features

- **Dark Theme UI**: Clean, authentic dark mode styling matching the modern X interface.
- **Fully Responsive**: Fluid layout adapted across mobile, tablet, and desktop viewports.
- **Left Navigation Sidebar**: Desktop nav with icons, badges, collapsible tablet/mobile layout, and profile badge.
- **Main Feed**:
  - Pinned sticky "For You" / "Following" tab navigation.
  - Interactive tweet composer box with media action icons.
  - Authentic post layout including verified badges, timestamps, embedded media, and interactive metrics (replies, reposts, likes, views).
- **Right Sidebar (Desktop)**:
  - Search bar with sticky blur header.
  - Premium subscription card.
  - "Today's News" and "What's Happening" trending sections.
  - "Who to follow" recommendations with direct follow actions.

---

## 🛠️ Built With

- **HTML5**: Semantic document structure.
- **Tailwind CSS (v4)**: Modern utility-first CSS framework.
- **Google Material Symbols**: Vector iconography.
